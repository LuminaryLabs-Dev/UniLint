# Start here: UniLint

1. Read the [README](../README.md) for the purpose, proof levels, CLI and boundaries.
2. Read [AGENTS.md](../AGENTS.md) before proposing code changes.
3. Read [architecture](../docs/architecture.md) and [dependencies](../docs/dependencies.md).
4. Follow [development](../docs/development.md) to install dependencies and run tests.
5. Read [evidence](../docs/evidence.md), [compatibility model](../docs/compatibility-model.md), [Oracle packs](../docs/oracle-packs.md), and [reference packs](../docs/reference-packs.md) before changing compatibility levels.
6. Read [signal graph](../docs/signal-graph.md), [known issues](../docs/known-issues.md), and [validation](../docs/validation.md) before reporting supported outcomes.
7. Verify actual code before editing; run checks and record factual outcomes afterward.

**Never infer Unity runtime success from static findings.** Preserve the no-Unity-automation and no-unlicensed-redistribution boundary.
