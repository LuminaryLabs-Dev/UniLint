# Oracle Packs

`oracle/versions/*.json` contains independently structured target-version facts. Oracle Packs do not bundle Unity binaries and are loaded dynamically from the local repository; adding a future pack does not require changing a hard-coded version list.

## Provenance model

```text
A  local-verified
   Evidence verified from local files the user is entitled to inspect.

B  human-curated
   Compact factual metadata entered by a human from authoritative sources.

C  project-metadata
   Facts supplied by the analyzed project's package/project files.

D  inferred
   Heuristic or inferred evidence that must remain explicitly uncertain.
```

The matching source modes are:

```text
A → local-verified-evidence
B → human-curated-facts
C → project-package-metadata
D → heuristic
```

Every committed Oracle Pack must declare structured provenance and all three offline-boundary flags:

```json
{
  "schemaVersion": "0.2",
  "provenance": {
    "level": "B",
    "label": "human-curated",
    "sourceMode": "human-curated-facts",
    "automatedIngestion": false,
    "unityProcessInvoked": false,
    "networkRequired": false,
    "sources": []
  }
}
```

`src/oracle/oracle.mjs` rejects packs that omit or contradict this provenance contract.

## What Oracle Packs are not

Oracle Packs are not generated by automatically crawling Unity Documentation, Unity APIs, the Asset Store, or Package Manager. They are not copies of Unity documentation. They contain only the compact compatibility facts UniLint needs.

The initial `6000.0` and `6000.3` packs remain **B-derived**. Their API-surface coverage still requires a local target reference pack before U3 can be awarded.
